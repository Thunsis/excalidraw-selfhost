## Features

- **Cloud scenes** — per-user, stored in SQLite on your machine. Sign in with any username; no passwords.
- **AI text-to-diagram** — the same in-app AI, self-hosted (any OpenAI-compatible endpoint).
- **Cloud library & AI chat history** — synced across your devices.
- **`excalidraw` CLI** — create scenes from Mermaid or natural language, list, show, export as PNG. Pure Node, no browser.
- **HTTPS by default** — with optional Cloudflare Tunnel for zero open ports.
- **Crash-safe backups & healthchecks** — `make backup`, `make check`, cron-friendly.

> Personal cloud only: one user, their drawings, fully owned. Real-time collaboration is out of scope.

## Quick Start

> **Requirements**: macOS · Node ≥ 24 · a clone of [excalidraw/excalidraw](https://github.com/excalidraw/excalidraw) (pinned commit) · optional Cloudflare account.

```bash
git clone https://github.com/Thunsis/excalidraw-selfhost.git
cd excalidraw-selfhost
cp .env.example .env
make install        # symlink launchd agents + configs
make build          # patch + build the frontend (one-time)
```

Start and open:

```bash
for job in ws-backend ai-backend caddy cloudflared; do
  launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.excalidraw.$job.plist
done
```

Open `https://localhost:3001` and sign in with any username.

Install the CLI (optional but recommended):

```bash
cd excalidraw-selfhost/cli
npm install && npm run fonts    # woff2 → ttf for PNG export
npm link                        # → `excalidraw` on PATH
excalidraw list                 # your cloud scenes
```

## CLI

```
excalidraw list [--json]                     list cloud scenes
excalidraw show <id> [--json]                scene detail (elements)
excalidraw create <name> [elements.json]     create scene from elements JSON
excalidraw update <id> [--name N] [--elements file.json]
excalidraw delete <id>
excalidraw ai "<prompt>" [--name N] [--dry-run] [--verbose] [--local]
excalidraw mermaid <file.mmd> [--name N] [--local]
excalidraw export <id> [out.json] [--png]   elements JSON, or PNG image with --png
excalidraw library get|put <file.json>       cloud library
excalidraw doctor                            env & connectivity check
```

```bash
excalidraw ai "用户登录流程" --name "login flow"   # LLM → mermaid → scene
excalidraw mermaid flow.mmd                        # mermaid file → scene
excalidraw export 42 scene.png --png               # scene → PNG
```

## Privacy

- All data lives in SQLite at `apps/ws-server/data/` — scenes, library, chat history, users.
- That directory is gitignored — your drawings never enter the repo.
- `make backup` snapshots the database crash-safely (works while running) and keeps 7 generations.

## FAQ

**Why not just use alswl/excalidraw-collaboration?**
Different goal — that project targets real-time multi-user collaboration; this one is a personal cloud. If you need collab, that project is the right choice.

**Why PolyForm Noncommercial?**
Personal and non-commercial use is free; commercial use requires a license. Upstream Excalidraw code remains MIT; bundled font slices are SIL OFL.

**Can I use the CLI without the AI server?**
Yes — `excalidraw mermaid file.mmd` converts a local Mermaid file directly. `excalidraw ai` needs the ai-server; both need ws-server for the cloud account.

**How do I upgrade when Excalidraw upstream moves?**
Deliberately slow (quarterly). See [docs/upgrade.md](docs/upgrade.md).
