## Features

Your own Excalidraw workspace, end to end:

- **Cloud scenes** — per-user, stored in SQLite on your machine. Sign in with any username; no passwords to manage.
- **AI text-to-diagram** — the same in-app AI, self-hosted (any OpenAI-compatible endpoint).
- **Cloud library & AI chat history** — synced across your devices.
- **`excalidraw` CLI** — create scenes from Mermaid files or natural language, list/show/export them — all pure Node, no browser. PNG export included.
- **HTTPS by default** — auto-redirect + HSTS; optional Cloudflare Tunnel for zero open ports.
- **WAL-safe backups & healthchecks** — `make backup`, `make check`, cron-friendly.

> **Scope**: this is a **personal cloud** — one user's drawings, library & AI, synced across devices, fully owned. Real-time multi-user collaboration is deliberately out of scope (see [FAQ](#faq)).

## Quick Start

> **Requirements**: macOS · Node ≥ 24 · a clone of [excalidraw/excalidraw](https://github.com/excalidraw/excalidraw) (pinned commit — see [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#5-frontend-customization--patch-as-single-source)) · optional Cloudflare account.

```bash
git clone https://github.com/Thunsis/excalidraw-selfhost.git
cd excalidraw-selfhost
cp .env.example .env            # fill in your values
make install                    # symlink launchd agents + configs
make build                      # patch + build the frontend (one-time)
```

Then start and open:

```bash
for job in ws-backend ai-backend caddy cloudflared; do
  launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.excalidraw.$job.plist
done
# open https://localhost:3001 — sign in with any username
```

Install the CLI (optional but recommended):

```bash
cd excalidraw-selfhost/cli
npm install && npm run fonts    # woff2 → ttf for PNG export
npm link                        # → `excalidraw` on PATH
excalidraw list                 # your cloud scenes
```

## CLI

The `excalidraw` CLI creates cloud scenes and exports PNGs without ever
opening a browser.

```
excalidraw list [--json]                     list cloud scenes
excalidraw show <id> [--json]                scene detail (elements)
excalidraw create <name> [elements.json]     create scene from elements JSON
excalidraw update <id> [--name N] [--elements file.json]
excalidraw delete <id>
excalidraw ai "<prompt>" [--name N] [--dry-run] [--verbose] [--local]
excalidraw mermaid <file.mmd> [--name N] [--local]
excalidraw export <id> [out.json] [--png]   elements JSON, or PNG image with --png
excalidraw library get|put <file.json>       cloud library
excalidraw doctor                            env & connectivity check
```

```bash
excalidraw ai "用户登录流程" --name "login flow"   # LLM → mermaid → scene
excalidraw mermaid flow.mmd                        # mermaid file → scene
excalidraw export 42 scene.png --png               # scene → PNG (pure Node)
```

<img src="https://raw.githubusercontent.com/Thunsis/excalidraw-selfhost/main/docs/cli-pipeline.png" alt="CLI pipeline" width="560">

The pipeline reuses the **official Excalidraw conversion & rendering
packages** — the CLI draws what the frontend AI draws. Mermaid flowchart and
sequence diagrams are fully supported; class/er/state/gantt are rejected with
a clear message (official converter limitation, same in the browser). See
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#2-diagram-type-support--official-converter-boundaries)
for the details and the verification method.

## Architecture

<img src="https://raw.githubusercontent.com/Thunsis/excalidraw-selfhost/main/docs/arch.png" alt="System architecture" width="640">

- **ws-server** (3020) — auth, scenes, library, AI chats (Express + better-sqlite3).
- **ai-server** (3016) — SSE proxy for AI text-to-diagram → any OpenAI-compatible endpoint.
- **caddy** (3001) — serves the patched frontend, reverse-proxies the two backends; HTTPS by default.
- **cloudflared** — optional tunnel for private HTTPS access.
- **excalidraw CLI** — talks to the same APIs; scenes from the terminal appear in your cloud workspace immediately.

## Privacy

- **All data lives in SQLite** at `apps/ws-server/data/` — scenes, library, chat history, users.
- That directory is **gitignored** — your drawings never enter the repo.
- JWT secret auto-generates on first run, persists across restarts.
- `make backup` — WAL-safe snapshot, keeps 7. `make check` — silent healthcheck, cron-friendly.

## FAQ

**Why not just use alswl/excalidraw-collaboration?**
Different goal — that project is built for real-time multi-user collaboration; this one is a **personal cloud** (your scenes, library and AI, synced across your own devices). If you need collab, that project is the right choice.

**Why PolyForm Noncommercial?**
Personal and non-commercial use is free; commercial use requires a license. Upstream Excalidraw code remains MIT; bundled Excalifont font slices are SIL OFL.

**Can I use the CLI without the AI server?**
Yes — `excalidraw mermaid file.mmd` converts a local Mermaid file directly. `excalidraw ai` needs the ai-server; both need ws-server for the cloud account.

**Is my data backed up?**
`make backup` snapshots the SQLite DB WAL-safely (works while running) and keeps 7 generations. Pair with cron for daily backups.

**How do I upgrade when Excalidraw upstream moves?**
Deliberately slow (quarterly). See [docs/upgrade.md](docs/upgrade.md) — pull, resolve conflicts by hand, re-export the patch.
